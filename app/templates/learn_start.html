What each parameter does

client_id identifies your application. Public by design.

redirect_uri is where {{ provider_display }} sends the user back. It must match your registration exactly — mismatches here are the most common OAuth error there is.

scope is what you are asking permission for. The user sees it on the next screen.

state is a random CSRF token. Your app has stored it and set a matching cookie, and will require both to agree on the way back.

response_type=code selects the Authorization Code flow.

{% if params.get("code_challenge") %}

code_challenge is a SHA-256 hash of a secret your app just generated. {{ provider_display }} will demand the original before issuing a token — that is PKCE.
